# APEPM-Code-Implementation
This code implements the APEPM model found on chemrxiv, the APEPM model paper available here: https://doi.org/10.26434/chemrxiv-2026-9swcr

# Notes:
If Bond overlap is 0 or less than 0 then a bond is not possible
